# Disclosure and data policy

This public repository is a **sanitized engineering portfolio**.

## Included

- deterministic synthetic market series;
- generic portfolio-allocation and research utilities;
- transparent transaction-cost assumptions;
- tests for causality, determinism, and accounting behavior;
- methodology notes that can be reviewed without private data.

## Excluded

- employer or client data;
- real trade records, account balances, or order logs;
- internal strategy names, symbols, parameters, reports, or team metrics;
- claims that a synthetic result represents live or historical investment performance.

Every generated report must retain the label:

> SYNTHETIC DEMONSTRATION — NOT INVESTMENT PERFORMANCE

The code is educational and is not investment advice.
