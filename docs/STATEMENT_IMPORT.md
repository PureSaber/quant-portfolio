# 本地账户导入与对账

`python -m quant_portfolio.account_import --config examples/statement/account.yaml --output account-review.json`

示例全部为合成账单：期初现金1000、100股成本10，入金500，卖出100股×11扣费5，期末现金2595、持仓零。真实数据放在仓库之外的私有目录，CSV 列名见示例。账户金额采用字符串十进制，代码保留前导零，成交及入金必须有唯一 ID，时间必须含时区。

导入器复用 QExec 精确账本，期初持仓记入 opening equity，资金流记入 external equity；不伪造历史成交，不把入金算作收益。金额或股数不能与期末账单一致时，输出 blocked 且不产生建议。所有账单文件计算 SHA-256，每次从完整输入重放，重复运行不累加成交。

增加 `--decision /path/to/decision.json` 可生成针对实际 NAV、现金和持仓的拟调仓差额；需要同一截止日、未过期且 paper_ready 的决策。只能调整 managed_symbols 中明确列出的证券。按整手、预计交易成本、单票上限、可卖股数和现金缓冲检查。尚未成交的卖出收入不能用于买入预算。

输出仅为本地人工复核资料，不会连接券商或下单。输入价格和可卖数量由用户账单确认；实际执行前仍须刷新交易状态和报价。跨公司行动的真实账单应在事件后取新的期初快照，或补齐经核验的事件导入；不得把不能对账的差额当作普通入金。个人分红税、融资融券、外币账户和零成本赠股不属于当前规范。
